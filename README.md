# The Legal Clarity Project

Website for **thelegalclarityproject.com** — a plain-language legal reference site by Lily Defendini. Translates complex legal terminology into clear, accessible definitions so everyone can understand their rights.

## What's in this repo

- `legal-clarity-theme/` — A custom WordPress theme ready to drop into cPanel.
- `INSTALL.md` — Step-by-step installation instructions for cPanel + WordPress.

## Quick start

1. Install WordPress on your cPanel hosting (most hosts have a one-click installer like Softaculous).
2. Upload the `legal-clarity-theme` folder to `/wp-content/themes/` via cPanel File Manager or FTP.
3. In your WordPress admin, go to **Appearance → Themes** and activate **The Legal Clarity Project**.
4. On first activation, the theme automatically creates all pages and populates the Dictionary, Amendments, and Know Your Rights content.
5. Set **Settings → Reading → Your homepage displays** to "A static page" and select **Home** as your homepage.

See [INSTALL.md](./INSTALL.md) for detailed steps.

## Sections

- **Home** — Hero, feature cards, popular terms, latest articles
- **Dictionary** — Full A–Z legal dictionary with search and letter filter
- **Know Your Rights** — All 27 Constitutional Amendments + 8 rights categories
- **Insights** — Articles and guides (blog)
- **About** — Project mission and creator
- **Contribute / Contact** — Suggest terms or reach out
- Legal pages: Privacy, Terms, Accessibility, Citation Guide, FAQ
